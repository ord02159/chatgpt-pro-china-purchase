## 国内购买 ChatGPT Pro 的具体流程

WildAI 帮助中心给出的 ChatGPT 订阅流程大致分为四步。不同商品或账号状态可能会出现额外验证，但基本顺序相近。

- 单次订阅：只购买当前一个月，到期后不继续；

长期方案的规则需要认真看。帮助中心提醒，部分多月套餐会按月自动续费。如果在 ChatGPT 官方页面直接取消订阅，可能导致尚未生效的预付月份无法继续使用。

### 2. 登录自己的 ChatGPT 账号

平台流程要求用户使用自己的 ChatGPT 账号登录，而不是把账号交给平台重新注册。

建议购买前确认：

- 当前登录的是准备升级的账号；
- 账号邮箱没有弄错；
- 账号没有处于异常登录或支付限制状态；
- 当前是否已经有 Plus 或 Pro 订阅；
- 是否存在未结束的多月订阅。

如果买错账号，平台帮助中心说明这类情况通常不属于自动退款范围。已完成履约、权益已经生效的订单，因选错产品、选错套餐或购买后不想使用，原则上不支持退款。

WildAI 的 ChatGPT 流程会引导用户在已经登录 ChatGPT 的同一浏览器中打开会话页面，复制一段 JSON 信息，再粘贴到订阅页面。

这段信息虽然不是普通密码，但属于敏感的账号会话凭证。不要发给客服以外的个人，也不要截图发到群聊或社交平台。完成开通后，建议检查账号的登录设备、订阅状态和安全设置。

系统识别账号邮箱后，需要再次核对是不是目标账号。确认无误后进入支付页面。

支付完成后，订单可能先显示“处理中”。平台帮助中心给出的自动开通时间通常是几分钟，但高峰期、账号风控或上游支付异常都可能延长处理时间。刚付款后不要立刻重复下单，否则可能产生重复扣款或多个待处理订单。

## 付款后没有开通怎么办？

付款后没有马上看到 Pro 权益，不一定代表订单失败。可以按下面顺序检查：

1. 进入平台订单记录，查看订单状态；
2. 登录 ChatGPT，刷新账单或套餐页面；
3. 确认登录账号邮箱与下单时识别的邮箱一致；
4. 等待页面提示的处理时间，不要立即重复支付；
5. 如果订单长时间没有变化，再联系平台客服并提供订单号、付款记录和当前套餐页面。

帮助中心还区分了自动升级和本地手动升级两种情况。有些订单支付后会自动处理，有些订单需要用户进入订单记录，按照“如何升级”的提示回到官方页面完成后续操作。

如果遇到账号已经扣款、但套餐没有变化的问题，重点不是再次支付，而是先确认订单到底属于哪一种升级方式。

## ChatGPT Pro 订阅不等于 OpenAI API

这是很多购买者容易混淆的地方。

ChatGPT Pro 是面向 ChatGPT 网页端或应用端的会员订阅。OpenAI API 则是给开发者调用模型的独立计费系统，两者不是同一个账户余额，也不是买了 Pro 就自动获得 API 额度。

WildAI 帮助中心明确说明，平台目前提供的是 ChatGPT 订阅代充，不提供 OpenAI 官方 API 额度充值。

因此：

- 想在 ChatGPT 网页端使用高级功能，考虑 Plus 或 Pro；
- 想在自己的程序、网站或自动化脚本中调用模型，需要单独配置 API；
- 想使用 Codex，也要确认你登录的是开通订阅的 ChatGPT 账号；
- API 账单、ChatGPT 会员账单和 Codex 使用额度不能混为一谈。

如果你的目标是开发接口，而不是使用 ChatGPT 网页端，购买 Pro 可能无法解决真正的问题。

- 是一次性购买还是按月续费；
